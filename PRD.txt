# 제품 용도
윈도우에서 리눅스 서버들의 디스크 용량을 체크하려고 해
최근 디스크가 100%가 되서 문제가 되는 일이 있었거든
디스크 용량을 체크할 수 있는 어플리케이션을 만들거야


## 서버 연결 config file
- 텍스트 기반
- IP, user, pw, path, 임계치 용량%


## 프로그램
- 서버가 여러개 있지만 1개 서버에서 시간을 읽어와서 언제 용량이 최신으로 갱신됬는지 표기 했으면 좋겠어
- 서버에서 시간을 가져오라고 하는 이유는 뭔가 프로그램이 멈췄는지 바로 알아챌수 있도록 하기 위해서야
- 체크하고자 하는 path 의 파티션의 total Size, 현재 사용량Size (+ %표기)
- 그리고 path 디렉터리에 있는 용량 상위 10개를 파티션 상태 표기한거에 밑에 접었다 펼수있게
- config파일의 서버를 등록할수 있게
- log 각 파티션들의 용량을 텍스트 파일을 남겨줘, 용량을 체크할때마다 기록해주고, log 파일을 일자별로 만들어줘
- 그리고 파티션 마다 임계치에 도달했을 경우 프로그램 배경이 빨강색으로 바뀌어 쉽게 알아챌수 있도록 (꼭 빨강색일 필요는 없어 너에게 색깔 선택권을 맡길게)
- 새로고침 버튼을 누르면 용량체크를 종료하고 바로 다시 용량체크를 시작하게 해줘
- log 버튼을 만들어 클릭하면 바로 log 디렉터리가 열리게 해줘

- 디자인 또한 너한테 선택권을 맡길게 잘 부탁해
